# MatchPlay Oyun Listesi ve Özellikleri

Bu dosya, MatchPlay platformunda kullanılabilecek tüm oyunları ve özelliklerini içerir.

## Oyun Özellikleri Açıklaması

Her oyun için aşağıdaki özellikler tanımlanmıştır:

- **Kategori**: Oyunun türü (masa_taş, spor, beceri, kart)
- **Min/Max Oyuncu**: Minimum ve maksimum oyuncu sayısı
- **Takım Sistemi**: Takım bazlı oynanıp oynanmadığı
- **Ekipman Gerekli**: Oyun için özel ekipman gerekip gerekmediği
- **Mekan Tipi**: indoor (kapalı alan), outdoor (açık alan), both (her ikisi de)
- **Ücret Beklentisi**: Genellikle ücretli mekan gerektirip gerektirmediği

## Veritabanı Yapısı Önerisi

### GameType Collection

```javascript
{
  _id: ObjectId,
  name: "Satranç",
  slug: "satranc",
  category: "beceri",
  icon: "chess",
  minPlayers: 2,
  maxPlayers: 2,
  hasTeams: false,
  requiresEquipment: false,
  equipmentDescription: "Satranç takımı (opsiyonel)",
  venueType: "both", // indoor, outdoor, both
  expectsFee: false,
  defaultDuration: 60, // dakika
  isActive: true,
  createdAt: Date,
  updatedAt: Date
}
```

### GameSession Collection (Kullanıcı Oyun İlanları)

```javascript
{
  _id: ObjectId,
  creatorId: ObjectId, // User reference
  gameTypeId: ObjectId, // GameType reference
  
  // Aşama 2: Açıklama
  title: "Kadıköy'de satranç turnuvası",
  description: "Eğlencesine bir satranç maçı",
  tags: ["#Eğlencesine", "#AcemiDostu"],
  
  // Aşama 3: Konum ve Zaman
  cityId: String,
  cityName: String,
  districtId: String,
  districtName: String,
  venueId: String,
  venueName: String,
  venueAddress: String,
  paymentType: "alman_usulu", // alman_usulu, ortak, ismarliyorum, ucretsiz
  startDate: Date,
  estimatedDuration: 120, // dakika
  
  // Aşama 4: Ekip
  totalPlayers: 2,
  neededPlayers: 1,
  teamAssignment: "manual", // manual, random, null
  skillLevel: "orta", // ilk_defa, az_bilenler, orta, iyi, profesyonel
  hasEquipment: true, // Kullanıcının ekipmanı var mı
  
  // Aşama 5: Oyuncu Kriterleri
  genderPreference: "herkes", // herkes, kizlar, erkekler, karma_dengeli
  
  // Oyun Durumu
  status: "open", // draft, open, full, cancelled, completed
  currentPlayers: [ObjectId], // Katılmış oyuncular
  pendingRequests: [ObjectId], // Bekleyen istekler
  
  createdAt: Date,
  updatedAt: Date
}
```

## Notlar

1. **Opsiyonel Takım Sistemi**: Tenis, bilardo gibi oyunlar hem tekli hem çiftli oynanabilir
2. **Ekipman**: "Opsiyonel" olarak işaretlenen oyunlarda kullanıcıya "Ekipmanın var mı?" sorusu sorulur
3. **Ücret Beklentisi**: Opsiyonel olan oyunlarda kullanıcı ücretsiz mekan da seçebilir
4. **Mekan Tipi**: 
   - `indoor`: Sadece kapalı alan
   - `outdoor`: Sadece açık alan  
   - `both`: Her ikisi de olabilir
